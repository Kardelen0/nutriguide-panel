## 🎯 Proje Hakkında

**NutriGuide Admin Panel**, NutriGuide ekosistemi için geliştirilmiş web tabanlı bir yönetim arayüzüdür. Bu panel sayesinde yöneticiler sisteme yeni sağlıklı tarifler ekleyebilir, kalori (kcal) ve fiyat (TL) bilgilerini güncelleyebilir, kategorileri (Bowl, Salata, Smoothie vb.) yönetebilirler. Modern ve hızlı bir web deneyimi sunmak amacıyla React ve Tailwind CSS ile tasarlanmıştır.

---

## ✨ Öne Çıkan Özellikler

| Özellik | Açıklama | Durum |
| :--- | :--- | :---: |
| 📝 **Yeni Tarif Ekleme Formu** | Form girdileriyle anlık tarif ve kalori/fiyat kaydı oluşturma. | ✅ Tamamlandı |
| 🎨 **Tailwind CSS Entegrasyonu** | Mobil uygulama tasarım sistemiyle uyumlu renk ve arayüz yapısı. | ✅ Tamamlandı |
| ⚡ **Vite Altyapısı** | Hızlı derleme ve akıcı geliştirici deneyimi (Hot Module Replacement). | ✅ Tamamlandı |
| 📱 **Responsive Tasarım** | Masaüstü ve tablet ekranlarına uyumlu esnek düzen. | ✅ Tamamlandı |

---

## 🛠️ Teknoloji Yığını

* **Frontend Framework:** React.js (Vite)
* **Stil / Tasarım:** Tailwind CSS
* **Programlama Dili:** JavaScript (ES6+)
* **Barındırma / Deployment:** Netlify / Vercel
